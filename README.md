# 📒 Mistake Notebook

### A Personal Study Assistant for Smarter Learning

Mistake Notebook is a learning project designed to help students track their incorrect answers, understand their mistakes, and revise them effectively.

## 🎯 Project Objective

The goal is to build a system that helps students learn from their mistakes instead of repeating them.

## ⚙️ Planned Features

- Automated quiz practice.
- Tracking incorrect answers.
- Saving mistakes in Google Sheets.
- Telegram bot integration.
- Automated revision reminders.
- Monitoring learning progress.

## 🛠️ Technologies

- Python
- n8n
- Telegram Bot API
- Google Sheets

## 🔄 How It Works

1. Students practice questions through Telegram.
2. The system checks their answers.
3. Incorrect answers are stored.
4. Saved mistakes can be reviewed later.
5. Automated reminders help students revise.
